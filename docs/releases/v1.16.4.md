## 本次更新

- **备份导入**：同步更新运行中的数据，避免导入结果被后续保存覆盖；导入失败不再清空图库。保持安全合并：当前同 ID 数据和设置优先，补入缺少的内容，不是覆盖恢复模式。

- **继续写**：在正文上下方提供入口，可连续追加后续并保存；接口中断或续写失败时保留已有正文。
- **字数设置**：按填写值生成字数要求和输出预算，不再固定使用同一上限或封顶为 5000 Token。实际字数不足会提醒，可继续追加。
- **历史与完整正文**：重新打开故事时恢复字数、主题等设置；转入聊天不再只保留前 700 个字符。
- **取消固定示例**：未配置模型时明确提示，不再用固定长度的本地示例冒充生成结果。
