## 1. 首次进入小手机

玩家打开小手机后，会先进入登录页面。

正常流程：

1. 点击 `登录`
2. 跳转到 Discord 验证
3. 加入指定社区
4. 完成身份验证
5. 返回小手机
6. 解锁进入桌面

如果 Discord 验证暂时不可用，作者可使用隐藏后门入口。

隐藏入口：

1. 在登录页连续点击 `登录` 三次
2. 出现后门输入框
3. 输入作者提供的 6 位临时码
4. 点击 `后门进入`

后门临时码每 48 小时刷新一次。

## 2. 配置文本大模型 API

进入路径：

`桌面 -> 设置 -> 文本大模型`

推荐默认使用 DeepSeek。

### DeepSeek 配置

接口地址：

```text
https://api.deepseek.com/v1
```

API Key：

```text
填写你的 DeepSeek API Key
```

模型名：

```text
deepseek-chat
```

如果使用 `v4pro`，模型名填写：

```text
v4pro
```

小手机使用 OpenAI 兼容格式，请确认你的服务商支持：

```text
/v1/chat/completions
```

---

## 3. 拉取或手动填写模型

在 `设置 -> 文本大模型` 页面：

1. 填写接口地址
2. 填写 API Key
3. 点击 `拉取模型`
4. 选择返回的模型

如果无法拉取模型，可以手动填写模型名，例如：

```text
deepseek-chat
v4pro
gpt-4o-mini
gemini-2.5-pro
claude-sonnet-4
```

模型是否可用取决于你的 API 服务商。

如果没有填写接口地址或模型，微信聊天和电话不会再生成固定本地回复。界面会直接显示缺少“接口地址”还是“模型”，让玩家知道当前没有真正连接到聊天 API。

如果 API 已经连到服务商但服务商返回错误，界面会直接显示实际 HTTP 错误码，例如 `HTTP 400`、`HTTP 401`、`HTTP 429` 或 `HTTP 500`。

## 4. 配置生图 API

进入路径：

`桌面 -> 设置 -> 生图配置`

这里用于配置 NAI 生图。微信、小红书、char 主动发图都会读取这里。

默认接口地址：

```text
https://image.novelai.net/ai/generate-image
```

API Key：

```text
填写你的 NAI API Key
```

模型：

```text
nai-diffusion-3
```

配置后可用于：

- 微信聊天 AI 生图
- 小红书封面生图
- char 主动发送图片
- AI 生图自动保存到相册

如果使用 NovelAI 官方地址但本机或部署环境连不上 `image.novelai.net:443`，生图会失败并显示连接/超时错误；这属于网络连通性问题，不是微信已经成功发出了图片。

## 5. 配置 TTS 语音

进入路径：

`桌面 -> 设置 -> TTS 语音`

可选类型：

- 浏览器语音：无需 Key
- OpenAI TTS：需要 OpenAI API Key
- Gemini TTS：需要 Gemini API Key
- 本地 HTTP：适合 GPT-SoVITS、IndexTTS、Piper 等本地服务

开启后，可用于：

- 微信语音条
- 电话语音
- 角色语音回复

## 6. 微信使用说明

进入路径：

`桌面 -> 微信`

微信支持：

- 文字聊天
- 语音条
- AI 生图
- 语音通话
- 视频通话
- 朋友圈

## 7. 预设使用说明

进入路径：

`桌面第二页 -> 预设`

每个软件都有独立预设，例如：

- 微信 / QQ
- 浏览器
- 小红书
- B站
- 电话
- 音乐
- 小剧场
- char 主动

预设条目可设置发送身份：

```text
system
user
assistant / model
```

建议：

- 规则、世界观、限制：使用 `system`
- 玩家要求：使用 `user`
- 示例回复：使用 `assistant / model`

## 12. 玩家最简流程

玩家只需要：

1. 安装 APK
2. 打开小手机
3. 点击登录
4. 完成 Discord 验证
5. 解锁进入桌面
6. 进入设置配置 API
7. 导入角色
8. 打开微信开始聊天

只配置文本大模型也可以正常使用。生图和 TTS 是增强功能。

## 2026-06-15 更新：NAI、主动生图和多玩家档案

### NAI 生图代理

生图仍然支持直接填写 NovelAI 官方接口和玩家自己的 NAI API Key。作者也可以部署服务端代理：

```text
https://你的域名/api/nai/generate-image
```

代理模式下，真实 NAI key 放在服务端环境变量 `NAI_API_KEY` 或 `NOVELAI_API_KEY`，玩家端可以不填 API Key。这样可以避免把 key 写进 APK 或公开前端包。

### 微信自动回复和主动发图

微信文字、语音、图片、表情、转账、红包和购物发送后都会默认触发角色回复，不需要玩家再点第二次发送。正在等待回复的消息不会重复塞进 AI 历史，避免角色围绕同一句话反复复读。

微信 AI 现在允许角色在合适场景低频主动发图，例如聊照片、风景、穿搭、礼物、梦境或场景氛围时输出 `[image prompt="..."]`。一次回复最多生成一张图。

### char 主动生图

`桌面第二页 -> char主动` 刷新后，系统会基于当天聊天或可读相册生成少量建议。若出现“发一张图”建议，只有玩家点“确认写入”后才会调用 NAI 生图、写入微信图片消息并同步保存到相册；刷新本身不会后台自动消耗生图额度。

### 多 User / 多玩家档案

`桌面第二页 -> User信息` 支持多个玩家身份档案。每个档案有独立昵称、身份、所在地、性格、喜好、雷点、关系设定和长期记忆。

- 当前选中的玩家档案会进入微信 AI 上下文。
- 可以新增、切换或删除玩家档案。
- 切换档案会同步当前昵称和 User 信息。
- 关闭“发送给 AI”后，该档案只保存在本机，不进入聊天提示词。
